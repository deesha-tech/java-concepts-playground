# Java Concepts Playground

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/deesha-tech/java-concepts-playground?quickstart=1)

**Don't just read Java. Run it.**
One runnable file per episode of our video series on production Java, from Deesha Tech Academy.
Each file has the buggy first version and the fix side by side, with the concepts named in the comments.

## Run an example

- **Online, in GitHub Codespaces:** press an episode's **Open in Codespaces** button below. It opens VS Code in your
  browser with Java 17 ready, opens the episode's `Main.java` and runs it once. Run it again any time with the
  **Run** link above `main`, or `java Main.java` in the terminal. You need a GitHub account; Codespaces uses your free
  monthly allowance.
- **On your machine (Java 17 or later):** `java Main.java` inside the episode's folder.
