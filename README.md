# Java Concepts Playground

**Don't just read Java. Run it.**
One runnable file per episode of our video series on production Java, from Deesha Tech Academy.
Each file has the buggy first version and the fix side by side, with the concepts named in the comments.

## Run an example

- **Online:** open the episode's "Run online" link below. Nothing to install.
- **On your machine (Java 17 or later):** `java Main.java` inside the episode's folder.
